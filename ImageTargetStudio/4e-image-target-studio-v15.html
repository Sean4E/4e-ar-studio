    How to use the CLI bundle
    1. Download the CLI bundle .zip below — contains {name}.json, original, cropped, thumbnail (263×350), and luminance (480×640) images.
    2. Unzip into your project's image-targets/ folder next to your AR engine code.
    3. Load at runtime via XR8.XrController.configure({ imageTargetData: [require('./image-targets/{name}.json')] }).
    4. For cylindrical and conical targets, set the physical dimensions in the 3D preview panel above — the bundle includes full CYLINDER / CONICAL metadata matching the image-target-cli output format.
